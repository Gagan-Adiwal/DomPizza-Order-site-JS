# 🍕 Food Ordering Website (Domino’s Style)

A modern, fully responsive **food ordering website** inspired by Domino’s.  
Built using **HTML, CSS, and JavaScript**, it allows users to **browse menus, check offers, and track their current location on Google Maps**.

---

## 🚀 Features
- **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.  
- **Navigation Bar & Footer** – Clean and modern UI for smooth browsing.  
- **Menu Page** – Displays different categories like **Pizza, Burgers, French Fries, Cold Drinks**, etc.  
- **Offers Page** – Showcases **5 discount coupons** for users.  
- **Location Tracking** – Detects **user’s current location** and displays it on **Google Maps**.  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Maps Integration:** Google Maps API
